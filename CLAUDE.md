# Контекст проекта для Claude Code

## Что это
Личное приложение одного ученика (владельца репозитория) для обучения игре на гитаре: программа по уровням,
задания на день, ноты с табулатурой (классика и испанская школа), аккорды с диаграммами и звуком, песни (рок, поп),
backing tracks, учебник по направлениям. Подробно — docs/CONCEPT.md, порядок работ — docs/PLAN.md,
решения — docs/DECISIONS.md, источники нот — docs/CONTENT.md.

## Среда
- Платформа и деплой — общие правила `/work/CLAUDE.md`; порт 127.0.0.1:3004, compose у владельца.
- Клиент — iPhone/iPad (PWA) и браузер. Один пользователь, авторизацию делает Caddy-замок.
- Языки — русский и английский (`src/lib/i18n.ts`, контент — пары `{ ru, en }`).

## Соглашения
- Документация и обсуждение — на русском; код, идентификаторы, коммиты — на английском.
- Новое решение → docs/DECISIONS.md. Push после каждого коммита. Тестовые серверы останавливать сразу после проверки.
- Только материал в общественном достоянии или свой. Тексты и мелодии/рифы песен под авторским правом в репозиторий
  не попадают; свои ноты владельца — только в /data («Мои ноты»).

## Стек и команды
SvelteKit (adapter-node, Svelte 5) + SQLite (better-sqlite3, Drizzle), ноты и табулатура — abcjs, звук аккордов —
свой синтез щипка (Karplus–Strong).

```sh
npm run dev | npm run check | npm test | npm run db:generate
node scripts/import-mutopia.mjs <guitar.json>   # повторить импорт пьес из Mutopia
```

# Guitar Tutor — концепция

Личное приложение одного ученика, который учится играть на гитаре. Главный вопрос каждой фичи: **помогает ли она
каждый день брать гитару и двигаться по программе.**

## Из чего состоит
1. **Программа** по образцу музыкального колледжа: уровни 1–8 (как семестры) и курсы — техника, ритм и песни, теория
   и гармония, слух, репертуар, импровизация; направления — классика, испанская гитара, рок, блюз, джаз, поп. Своя
   программа по образцу структуры (в т. ч. Berklee), не официальная программа какого-либо колледжа.
2. **Мой уровень** в настройках (или проверка уровня) — от него строятся программа и задания.
3. **Задания на сегодня** на выбранное время (15–90 мин) с таймером.
4. **Ноты с табулатурой**: классика и испанская школа из изданий в общественном достоянии (Сор, Агуадо, Таррега,
   Джулиани, Каркасси, Карулли, Санс, Бах) — звук, темп, подсветка.
5. **Аккорды**: диаграммы с пальцами, звучат по тапу; открытые, септаккорды, sus, баррэ, пауэр-аккорды.
6. **Песни**: русский рок 80-х–2000-х и другие — аккорды и схема (без текстов и рифов, они под авторским правом);
   свои песни с текстами — в «Мои песни» только на NAS.
7. **Backing tracks**: аккомпанемент по сетке аккордов в стилях (рок, блюз-шаффл, фламенко, баллада).
8. **Учебник** по направлениям: классика, испанская гитара (самоучитель по образцу школ Агуадо и Сора + основы
   фламенко), поп и рок, джаз и блюз.
